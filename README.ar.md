# Board Arena — دليل التشغيل

نسخة أولية قابلة للتشغيل من منصة ألعاب استراتيجية، تضم **أبالون وكوريدور والداما وغوموكو والطاحونة وأربع قطع متصلة** بواجهة داكنة عربية وإنجليزية. منطق الألعاب مستقل عن الواجهة، ويمكن اختباره دون متصفح. يحتوي المشروع على تطبيق React وخادم Node.js وقاعدة SQLite وإعدادات Android وiOS عبر Capacitor.

## التشغيل على الكمبيوتر

ثبّت Node.js بالإصدار 24 أو أحدث، ثم نفّذ داخل مجلد المشروع:

```sh
npm ci
cp .env.example .env
npm run dev
```

افتح `http://localhost:5173`. يمكنك اللعب على جهاز واحد أو ضد الذكاء الاصطناعي دون إنشاء حساب. لتجربة اللعب الشبكي، افتح التطبيق في ملف متصفح آخر أو نافذة خاصة لإنشاء جلستين مختلفتين، ثم أنشئ غرفة خاصة وأدخل رمزها لدى اللاعب الآخر.

لبناء نسخة التشغيل:

```sh
npm test
npm run build
npm start
```

افتح بعدها `http://localhost:8787`. تُنشأ قاعدة البيانات داخل `data` تلقائيًا. نجحت اختبارات المشروع الـ158، وتشمل حالات حدودية في القواعد، صلاحيات الخادم، استعادة الاتصال وتفاعل مكونات الواجهة.

## ما يعمل

- قواعد أبالون الأساسية كاملة: الحركة في ستة اتجاهات، المجموعات المتصلة، الحركة الجانبية، الدفع بالأغلبية، إخراج الكرات والفوز بإخراج ست كرات.
- قواعد كوريدور: حركة القطعة، القفز المستقيم والقطري بشروطه، الجدران ومعاينتها، منع التداخل والتقاطع، والتحقق من بقاء طريق لكلا اللاعبين.
- الداما الإنجليزية 8×8: الأخذ الإجباري والمتسلسل، ترقية الملك، الفوز بالأخذ أو الحصار، والتعادل بالتكرار أو 40 دورًا لكل لاعب دون تقدم.
- غوموكو الحرة 15×15: تأكيد وضع القطعة، والفوز بخمس قطع أو أكثر في أي اتجاه، والتعادل عند امتلاء اللوحة.
- الطاحونة (Nine Men’s Morris): وضع تسع قطع، التحريك، الطيران عند بقاء ثلاث قطع، تكوين الصفوف الثلاثية وحماية قطعها، والتعادل بالتكرار.
- أربع قطع متصلة (Connect Four): إسقاط القطع بالجاذبية على لوحة 7×6، ومنع الأعمدة الممتلئة، وفحص الفوز والتعادل.
- اللعب المحلي، ثلاثة مستويات للذكاء الاصطناعي، الغرف الخاصة والمطابقة السريعة، والتصنيف المستقل لكل لعبة.
- حساب ضيف أو بريد إلكتروني، الملف الشخصي، الإحصاءات الفعلية، المفضلة، سجل المباريات ولوحات المتصدرين والأصدقاء.
- المؤقتات، التراجع في اللعب المحلي فقط، إعادة المباراة، الاستسلام، عرض التعادل بين لاعبين، الرموز التعبيرية، النتائج، الصوت والاهتزاز.
- خادم يتحقق من الدور والحركة والنتيجة والوقت، مع استعادة المباراة وحماية من تكرار إرسال الحركة.

## تطبيق الهاتف

```sh
npm run mobile:android
npx cap open android
```

```sh
npm run mobile:ios
npx cap open ios
```

أُنشئت مشاريع Android وiOS وتمت مزامنتها. لم يُبنَ ملف APK أو IPA في بيئة العمل الحالية. يحتاج Android إلى أدوات البناء المناسبة وJava 21؛ ويحتاج iOS إلى جهاز Mac وXcode. يوجد مسار عمل GitHub جاهز لبناء APK تجريبي بعد رفع المشروع.

للعب عبر الإنترنت من الهواتف، انشر الخادم ثم ضع عنوانه الآمن في `VITE_SERVER_URL` وأعد البناء. يوضح [دليل النشر](docs/DEPLOYMENT.md) الإعدادات، أسماء المتغيرات وخطوات ربط Google وApple.

## ما يحتاج إكمالًا خارجيًا

مستودع المشروع هو [3thelast-glitch/games](https://github.com/3thelast-glitch/games). لم يُنشر الخادم بعد. تسجيل Google وApple مهيّأ في الكود لكنه يحتاج بيانات التطبيقات واختبار الحسابات الحقيقية. كما يلزم اختبار الواجهة على أجهزة ومتصفحات فعلية قبل النشر العام؛ تعذّر الفحص البصري بالمتصفح في بيئة العمل الحالية.

LAN والشطرنج وReversi وMancala مؤجلة كما هو موضح داخل التطبيق. التحقق من البريد، استعادة كلمة المرور، حذف الحساب، التنبيهات الخلفية والتشغيل على عدة خوادم ليست ضمن هذه النسخة. التفاصيل في [حالة التسليم](docs/STATUS.md)، وبنية إضافة ألعاب جديدة في [دليل المعمارية](docs/ARCHITECTURE.md).
