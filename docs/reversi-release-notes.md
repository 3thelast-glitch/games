# Reversi release notes

Reversi is promoted from the upcoming-games list into the playable Board Arena catalog.

Included in this release:

- Standard 8×8 Reversi rules with automatic forced passes and disc-count scoring.
- Local two-player mode and shared AI difficulty levels.
- Online matchmaking, private rooms and ranked matches through the authoritative server.
- English and Arabic localization.
- Responsive touch-friendly board, legal-move hints, score display, last-move marker and reduced-motion support.
- Dedicated rule, UI, server and Playwright regression coverage.
